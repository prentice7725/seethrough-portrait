# Document moved

The automatic rig, expression pack, Spine exporter, browser preview, and motion
guard design now belong to the independent
[`portrait-autorig`](https://github.com/prentice7725/portrait-autorig)
repository.

The original feasibility record is preserved there at
`docs/PORTRAIT_AUTO_RIG_FEASIBILITY_v0.1.md`.

Static reconstruction findings discovered during that experiment—fidelity
repair and seam validation—remain in `seethrough-portrait` because they are
part of producing Portrait Bundle v1.
